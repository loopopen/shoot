# shoot
[![Language](https://img.shields.io/badge/language-中文-blue.svg)](https://github.com/loopopen/shoot/blob/main/README.zh-cn.md)
              
A pack of tools for "go generate".

# How to use?

```zsh
Usage: shoot <subcommand> [options]
These are all the sub commands supported as of now:
new [-opt] [-getset] [-json] [-exp] [-tagcase=<case>] [-sign=<prefix>] [-type=<Type> | -file=<GoFile>] [dir] [-sep] [-v]
enum [-bit] [-json] [-text] [-sql] [-gorm] [-type=<Type> | -file=<GoFile>] [dir] [-sep] [-v]
rest [-sign=<prefix>] [-type=<Type> | -file=<GoFile>] [dir] [-sep] [-v]
map [-path=<path>] [-alias=<alias>] [-to=<DestType>] [-way=<way>] [-i] [-type=<SrcType> | -file=<GoFile>] [dir] [-sep] [-v]
```

`new` and `rest` instructions use `@` by default, for example `//@new` and
`//@Get("/users/{id}")`. Use `-sign=<prefix>` to select another instruction
prefix; `-sign='shoot:'` keeps compatibility with the former `//shoot:` form.

## using go1.24+ (SUGGESTED)

### why 1.24
[Tool dependencies](https://golang.google.cn/doc/modules/managing-dependencies#tools)

### install
```zsh
go get -tool github.com/loopopen/shoot/cmd/shoot@latest
```

### generate instruction examples
```go
//go:generate go tool shoot new -getset -json -type=YourType

//go:generate go tool shoot new -getset -json -file=$GOFILE

//go:generate go tool shoot enum -json -type=YourEnum

//go:generate go tool shoot rest -type=YourClient

//go:generate go tool shoot map -path=../destpath -type=YourSrcType
```

```zsh
go generate			# run in the current directory
go generate ./...	# recursively run in the current directory and its subdirectories
```

package example

// NewUser constructs a new instance of type User
func NewUser(id int, name string, age int) *User {
	return &User{
		id:   id,
		name: name,
		age:  age,
	}

// Id gets the value of field id

	return u.id

}

	u.name = name_

## REST client example:
```go
package example

import (
	"context"
	"fmt"
	"time"

	"github.com/loopopen/shoot"
)

type User struct {
	ID   string `json:"id"`
	Name string `json:"name"`
}

type Client interface {
	//@headers={Tenant-Id:123}
	shoot.RestClient[Client]

	//@Get("/users/{id}")
	//@alias={userID:id},{pageSize:size}
	GetUser(ctx context.Context, userID string, pageSize int, opts ...shoot.RequestOption) (*User, *shoot.Response, error)

	//@Post("/users")
	CreateUser(ctx context.Context, user User, opts ...shoot.RequestOption) (*User, *shoot.Response, error)

	//@Get("/download")
	Download(ctx context.Context) (*shoot.StreamResponse, error)
}

func Example() error {
	client := shoot.NewRest[Client](
		shoot.BaseURL("https://api.example.com"),
		shoot.Timeout("3s"),
		shoot.DefaultHeaders(map[string]string{"X-App": "example"}),
	)

	user, response, err := client.GetUser(
		context.Background(),
		"a/b", // path parameters are URL-escaped by generated clients
		20,
		shoot.WithBearerToken("token"),
		shoot.WithHeader("X-Request-ID", "request-123"),
		shoot.WithQueryParam("locale", "en"),
		shoot.WithTimeout(2*time.Second),
	)
	if err != nil {
		return err
	}
	if response.IsFailure() {
		return fmt.Errorf("request failed: %s", response.String())
	}
	_ = user
	return nil
}
```

Run `shoot rest` after declaring the interface. A generated method can accept
`...shoot.RequestOption` to customize one request. The variadic parameter must
be named; placing it last is recommended. Available options are:

* `WithHeader`, `WithHeaders`, `WithBearerToken`, `WithBasicAuth`,
  `WithAccept`, `WithContentType`, and `WithUserAgent`
* `WithQueryParam` and `WithQueryParams`
* `WithCookie` and `WithCookies`
* `WithTimeout` and `WithDeadline`
* `WithRequestModifier` for custom request mutations

Request options take precedence over generated defaults, client-level default
headers, and `@headers` instructions. A non-positive `WithTimeout` disables the
client-level timeout for that request.

Generated clients URL-escape path parameters. `GET` and `DELETE` parameters
that are not used in the path become query parameters; a query map must have
string keys. `POST`, `PUT`, and `PATCH` accept at most one non-path body
parameter, and may also have no body.

`*shoot.Response` caches and closes the response body. HTTP failure responses
are still returned and, when a result type is declared, decoded; inspect
`IsSuccess`, `IsFailure`, `StatusCode`, `Body`, or `String`. A
`*shoot.StreamResponse` leaves the body open, so the caller must close it.

## generated file example 3:
```go
// Code generated by "shoot map -path=../../domain/model -alias=domain -type=*"; DO NOT EDIT.

package dto

import domain "mapperexample/domain/model"

// ToDomain converts receiver to type domain.Order
func (o *Order) ToDomain() *domain.Order {
	if o == nil {
		return nil
	}
	order_ := new(domain.Order)
	order_.ID = o.ID
	order_.Amount = o.StringToDecimal(o.Amount)
	order_.Status = o.Status
	order_.OrderTime = o.StringToTime(o.OrderingTime)
	if o.Address != nil {
		order_.Address = *o.Address.ToDomain()
	}
	o.writeDomain(order_)
	return order_
}

// FromDomain reads from type domain.Order, then writes back to receiver and returns it
func (o *Order) FromDomain(order_ *domain.Order) *Order {
	if order_ == nil {
		return nil
	}
	if o == nil {
		o = new(Order)
	}
	o.ID = order_.ID
	o.Amount = o.DecimalToString(order_.Amount)
	o.Status = order_.Status
	o.OrderingTime = o.TimeToString(order_.OrderTime)
	o.Address = new(OrderAddress).FromDomain(&order_.Address)
	o.readDomain(order_)
	return o
}
```
